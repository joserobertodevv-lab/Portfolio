## Publicação
Pode ser publicado diretamente no Vercel, GitHub Pages ou qualquer hospedagem estática.

## Antes de publicar
1. Troque o link do GitHub no `index.html`.
2. Troque o e-mail.
3. Substitua os cards por screenshots reais dos projetos.
4. Adicione links reais para os repositórios/demos.
5. Se quiser, altere as variáveis de cor no começo de `assets/css/style.css`.
